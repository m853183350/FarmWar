# 商店和经济系统

本章节记录商店和经济系统的核心职责、资源类型、交易机制和经济平衡。

## 目标

- 定义游戏中的资源类型与流通方式
- 实现商店买卖功能
- 维护经济平衡，确保游戏节奏合理

## 范围

- 资源类型：金币、食物、材料、特殊货币等
- 商店功能：购买种子、装备、道具；出售收获物
- 价格机制：基础价格、浮动价格、折扣
- 经济产出：作物收获 → 出售 → 金币 → 购买装备/种子 → 扩大生产

## 核心概念

- `EconomyManager` 管理全局资源池
- `Shop` 处理买卖逻辑
- `PriceTable` 定义物品价格
- `Transaction` 记录每笔交易（用于统计/回放）
