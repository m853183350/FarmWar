# 目录结构

本文档定义 FarmWar 项目的完整文件目录结构，涵盖场景、脚本、资源、资产和文档五个顶层目录。

---

## 设计原则

1. **按系统分包** — 顶层按系统（而非文件类型）划分，同一系统的场景、脚本、资源就近存放，降低跨目录查找成本
2. **Docs 镜像 scripts** — 每个 `.gd` 文件对应一个 `.md` 文档，`Docs/` 目录结构镜像 `scripts/`
3. **单一职责目录** — 每个子目录只包含属于该系统的内容，避免跨系统耦合
4. **预留扩展空间** — 每个系统目录保留 `special/` 或 `variants/` 等子目录，便于后续扩展

---

## 顶层结构

```
farm-war/
├── project.godot              # Godot 项目配置文件
├── main.tscn                  # 主场景入口（空 Node2D，待填充）
├── CLAUDE.md                  # Claude Code 项目指南
├── export_presets.cfg         # 导出预设（后续创建）
│
├── scenes/                    # 场景文件 (.tscn)
├── scripts/                   # GDScript 脚本 (.gd)
├── resources/                 # 资源文件 (.tres)
├── assets/                    # 原始资产（美术、音频、字体）
└── Docs/                      # 项目文档
```

## scenes/ — 场景文件

每个子目录对应一个游戏系统，存放该系统相关的 `.tscn` 场景文件。

```
scenes/
├── world/                     # 世界/地图场景
│   ├── world.tscn             #   主世界场景（地图容器）
│   └── tile.tscn              #   单一地块场景（网格单元）
│
├── crops/                     # 作物场景
│   ├── crop.tscn              #   通用作物基类场景
│   ├── plants/                #   各科植物场景
│   │   ├── wheat.tscn         #     小麦（禾本科）
│   │   ├── rice.tscn          #     水稻（禾本科）
│   │   └── ...                #     （按科扩展）
│   └── harvest/               #   收获物/掉落物场景
│
├── units/                     # 作战单位场景
│   ├── unit_base.tscn         #   单位基类场景
│   ├── player_units/          #   玩家单位
│   ├── enemy_units/           #   敌方单位模板
│   └── projectiles/           #   弹射物场景
│
├── buildings/                 # 建筑场景
│   ├── building_base.tscn     #   建筑基类场景
│   ├── defensive/             #   防御类建筑（墙、塔等）
│   ├── production/            #   生产类建筑（工厂等）
│   └── decorative/            #   装饰类建筑
│
├── items/                     # 道具场景
│   ├── item_base.tscn         #   道具基类场景
│   ├── consumables/           #   消耗品
│   └── equipment/             #   装备类道具
│
├── enemy/                     # 敌人场景（独立于 units，侧重 AI 实体）
│   ├── enemy_base.tscn        #   敌人基类场景
│   └── types/                 #   各类型敌人
│
├── ui/                        # UI 场景
│   ├── hud.tscn               #   主 HUD（常驻信息栏）
│   ├── main_menu.tscn         #   主菜单
│   ├── shop/                  #   商店界面
│   ├── inventory/             #   仓库/背包界面
│   ├── tech_tree/             #   科技树界面
│   ├── settings/              #   设置界面
│   ├── game_over/             #   结算界面
│   ├── debug_console.tscn     #   调试控制台（"/" 键激活）
│   ├── debug_overlay.tscn     #   调试叠加层（F3 开关）
│   └── components/            #   可复用 UI 组件（按钮、卡片、提示框等）
│
└── meta/                      # 局外/元场景
    ├── boot.tscn              #   启动/加载场景
    ├── lobby.tscn             #   大厅/主界面
    └── progression.tscn       #   局外成长界面
```

## scripts/ — GDScript 脚本

每个子目录对应一个游戏系统，存放该系统相关的 `.gd` 脚本文件。目录名与 `scenes/` 保持一致。

```
scripts/
├── autoload/                  # Godot Autoload 全局单例
│   ├── game_state.gd          #   全局游戏状态管理
│   ├── event_bus.gd           #   全局事件总线
│   ├── resource_manager.gd    #   资源管理器
│   ├── data_manager.gd        #   数据/存档管理
│   ├── audio_manager.gd       #   音频管理
│   ├── tick_system.gd         #   Tick 系统（逻辑时钟，与渲染分离）
│   ├── debug_console.gd       #   调试控制台（指令注册、解析路由）
│   └── config.gd              #   全局配置常量
│
├── world/                     # 地块系统 — 系统 1
│   ├── tile.gd                #   地块类（TileData 封装）
│   ├── tile_manager.gd        #   地块管理器（map 存储与查询）
│   ├── terrain_generator.gd   #   地形生成器
│   ├── terrain_types.gd       #   地形类型枚举与定义
│   └── world_manager.gd       #   世界管理器（昼夜、季节等）
│
├── crops/                     # 作物系统 — 系统 2
│   ├── crop.gd                #   作物基类
│   ├── crop_manager.gd        #   作物管理器（种植/收获生命周期）
│   ├── growth_system.gd       #   生长系统（阶段、条件判定）
│   └── plant_family.gd        #   植物"科"定义（数据类）
│
├── units/                     # 作战单位系统 — 系统 3
│   ├── unit_base.gd           #   单位基类（移动、攻击、生命值）
│   ├── unit_manager.gd        #   单位管理器（生成、编队、指令）
│   ├── combat_system.gd       #   战斗计算（伤害公式、护甲等）
│   ├── pathfinding.gd         #   寻路系统
│   └── formation.gd           #   编队系统
│
├── economy/                   # 商店和经济系统 — 系统 4

│
├── buildings/                 # 建筑系统 — 系统 5
│   ├── building_base.gd       #   建筑基类

│   ├── defense_building.gd    #   防御建筑
│   └── production_building.gd #   生产建筑
│
├── storage/                   # 仓库系统 — 系统 6

│   ├── item_data.gd           #   物品数据结构

│   └── consumable.gd          #   消耗品逻辑
│
├── enemy/                     # 敌人 AI — 系统 8
│   ├── enemy_base.gd          #   敌人基类（属性、状态）
│   ├── enemy_manager.gd       #   敌人生成与波次管理
│   ├── ai_controller.gd       #   AI 行为控制器
│   ├── ai_behaviors/          #   具体 AI 行为
│   │   ├── patrol.gd          #     巡逻行为
│   │   ├── chase.gd           #     追击行为

│   ├── weather_manager.gd     #   天气管理器

│   ├── game_over_ui.gd        #   结算界面
│   ├── tooltip.gd             #   提示框组件
│   ├── minimap.gd             #   小地图
│   ├── debug_console_ui.gd    #   调试控制台 UI 逻辑
│   └── debug_overlay.gd       #   调试叠加层
│
├── meta/                      # 局外系统 — 系统 12-14
│   ├── game_flow.gd           #   游戏流程控制（开始/结束/重新开始）
│   ├── progression.gd         #   局外成长系统（永久升级）
│   ├── save_system.gd         #   存档系统
│   └── settings.gd            #   设置逻辑

└── utils/                     # 通用工具函数（不归属任何系统）
```
