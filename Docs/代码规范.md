# 语言与格式

1. 使用 GDScript，Godot 4.6 语法
2. 行首缩进使用制表符 `\t`，非空格
3. 文件编码 UTF-8，LF 换行
4. 行宽不超过 120 字符
5. 文件末尾保留一个空行

# 命名

| 类型 | 规则 | 示例 |
|------|------|------|
| 文件/目录 | snake_case | `player_controller.gd` |
| 类名 | PascalCase | `PlayerController` |
| 变量/函数 | snake_case | `move_speed`, `take_damage()` |
| 常量 | UPPER_SNAKE_CASE | `MAX_HEALTH` |
| 信号 | snake_case，过去式 | `health_changed`, `died` |
| 私有成员 | `_` 前缀 | `_current_health`, `_on_timer()` |
| `@export` 变量 | 与普通变量相同 | `@export var attack_power: int` |
| 枚举值 | UPPER_SNAKE_CASE | `enum State { IDLE, RUNNING }` |

# 文件结构

1. 每个文件只放一个类，类名与文件名一致
2. 目录结构：

```
scenes/          # 场景文件 (.tscn)
  player/
  enemy/
  ui/
scripts/         # GDScript
  player/
  enemy/
  ui/
  autoload/      # 全局脚本
resources/       # 资源文件 (.tres)
assets/          # 美术、音效等
Docs/            # 文档
```

# 类内声明顺序

```
extends Node
class_name MyClass
## 文档注释

# 1. 信号
signal health_changed(old: int, new: int)

# 2. 枚举
enum State { IDLE, MOVING, DEAD }

# 3. 常量
const MAX_HEALTH := 100

# 4. @export 变量
@export var move_speed: float = 200.0

# 5. 公开变量
var is_alive: bool = true

# 6. 私有变量
var _current_health: int = MAX_HEALTH

# 7. @onready 变量
@onready var sprite: Sprite2D = $Sprite2D

# 8. 生命周期方法
func _ready() -> void:
	pass

func _process(delta: float) -> void:
	pass

# 9. 公开方法
func take_damage(amount: int) -> void:
	pass

# 10. 私有方法
func _on_timer_timeout() -> void:
	pass
```

# 类型与静态类型

1. **必须**标注类型，不依赖类型推断（`:=` 仅用于常量）
2. 函数参数和返回值必须标注类型
3. 可空类型显式标注：`var target: Node = null` → 用 `@onready var target: Node` 替代

```
# ✅ 正确
var health: int = 100
func apply_damage(amount: int) -> void:

# ❌ 错误
var health = 100
func apply_damage(amount):
```

# 注释

1. 文档注释用 `##`，普通注释用 `#`
2. 每个类顶部必须有文档注释，说明用途
3. 复杂逻辑、临时的 workaround 必须注释原因
4. 信号和公开方法建议加 `##` 注释

```
## 玩家控制器，处理输入和移动。
class_name PlayerController extends CharacterBody2D

## 受到伤害，若血量归零则发出 [signal died]。
func take_damage(amount: int) -> void:
	# 护甲减伤临时用常量，待替换为装备系统
	_health -= amount / 2
```

# 信号

1. 命名用过去式：`died`, `health_changed`, `item_collected`
2. 参数类型必须声明
3. 优先用编辑器连接信号，动态连接用 `.connect()` 并在 `_exit_tree()` 中断开

```
signal coin_collected(value: int)
signal door_opened(id: StringName)

# 动态连接
func _ready() -> void:
	area.area_entered.connect(_on_area_entered)

func _exit_tree() -> void:
	area.area_entered.disconnect(_on_area_entered)
```

# 节点引用

1. 用 `@onready` + `$` 获取子节点，不要在 `_ready()` 里赋值
2. 唯一命名子节点，禁止用 `get_node("..")` 向上引用

```
@onready var health_bar: ProgressBar = $UI/HealthBar
@onready var animation_player: AnimationPlayer = $AnimationPlayer
```

# 资源加载

1. 常用资源用 `preload`，运行时按需加载用 `load`
2. preload 路径写常量，放在文件顶部

```
const BULLET_SCENE: PackedScene = preload("res://scenes/bullet/bullet.tscn")
const HIT_SOUND: AudioStream = preload("res://assets/sfx/hit.wav")
```

# 场景设计

1. 根节点类型与脚本 `extends` 类型一致
2. 场景职责单一，复杂 UI 拆分子场景
3. 跨场景共享逻辑用 Autoload，不用跨场景引用
4. physics_layers 和 collision_mask 用项目设置中命名的物理层

# 设计原则

1. 组合优于继承：用子节点 + 组件脚本替代深层继承
2. `@export` 暴露可配置项，避免硬编码
3. 用 `match` 替代长 `if-elif` 链
4. `if` 条件不嵌套超过 3 层，超出则提取函数
5. 禁止魔法数字：用命名常量
6. 空值检查：外部依赖（`get_node` 除外）使用前判空
7. 用 `Tween` 做动画，不用 `_process` 里手写插值

# 文档

1. 每个 `.gd` 文件对应一个 `.md` 文档，放在 `Docs/` 下，目录镜像 `scripts/` 结构
