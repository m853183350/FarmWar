# 作物系统

本章节记录作物系统的核心职责、概念、类型、生长机制和与其它系统的交互。

## 目标

- 定义游戏中"作物"的基本单元与生命周期
- 以现实生物学"科"为分类单位，每科有独特收益、科技树和兵种
- 规范种植、生长、收获全流程

## 范围

- 作物分类：按"科"划分（禾本科、豆科、茄科、十字花科等）
- 作物生命周期：播种 → 发芽 → 生长 → 成熟 → 收获
- 生长条件：水分、肥力、温度、光照等环境因素
- 作物收益：收获物类型、数量、品质
- 与地块系统的交互：可耕种性、肥力值
- 与科技树系统的交互：解锁新作物品种、提升产量

## 核心概念

- `Crop`（作物）是种植在地块上的可生长实体
- `PlantFamily`（科）定义作物的生物学分类
- `GrowthStage` 定义作物的生长阶段
- `CropYield` 定义收获产物（食物、材料、种子等）

### 生长速度公式

若非特别说明，所有作物均套用这一公式

```
湿度衰减强度 = 2 （暂定）

## 湿度
if 地块湿度 >= 作物最低湿度 && 地块湿度 <= 作物最高湿度:
    湿度修正值 = 1
else if 地块湿度 > 作物最高湿度:
    湿度修正值 = 1 / (1 + 湿度衰减强度×(地块湿度 - 作物最高湿度)) ## 有边际递减效应
else if 地块湿度 < 作物最低湿度:
    湿度修正值 = 地块湿度 / 作物最低湿度 ## 线性，注意除0问题

## 肥力
肥力修正值 = sqrt(作物肥力系数 * 地块肥力)

## 温度
if 地块温度 >= 作物最低温度 && 地块温度 <= 作物最高温度:
    温度修正值 = 1
else if 地块温度 >= 作物最高温度:
    温度修正值 = (作物最高温度 - 地块温度) / 作物温度耐受力 + 1 ## 线性，从最高温度的1，经过耐受温度后归零
else if 地块温度 <= 作物最低温度:
    温度修正值 = (地块温度 - 作物最低温度) / 作物温度耐受力 + 1


速度修正值 = 湿度修正值 * 温度修正值 * 独立速度修正值
产量修正值 = 1 * 肥力修正值 * 独立产量修正值
```

在作物内部监听地块肥力、温度、湿度、独立修正值变化信号（尽量不要用全局，避免一个地块更新导致全体更新），当发生变化时重新计算生长速度和产量
