# 建筑系统

本章节记录建筑系统的核心职责、建筑类型、放置规则和升级机制。

## 目标

- 定义可建造、可交互的"建筑"实体
- 规范建筑放置条件、占用规则、建造消耗
- 实现建筑升级与拆除

## 范围

- 建筑类型：防御建筑（城墙、箭塔）、生产建筑（工坊、磨坊）、功能建筑（仓库、研究室）
- 放置规则：地块可建造性检查、占地面积、相邻限制
- 建造消耗：资源需求、建造时间
- 建筑属性：生命值、防御值、功能效果

## 核心概念

- `BuildingBase` 是所有建筑的基类
- `BuildingManager` 管理建筑放置、拆除、升级
- `DefenseBuilding` 防御类建筑（血量、攻击、范围）
- `ProductionBuilding` 生产类建筑（自动产出资源）
