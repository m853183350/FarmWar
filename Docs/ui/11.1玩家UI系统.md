# 玩家 UI 系统

本章节定义玩家 UI 系统的完整框架：层级架构、界面清单、交互规范和信号通信。细节由后续文档补充。

---

## 设计原则

从 `整体设计.md` 的 **#主要玩法** 提取以下 UI 设计约束：

| 原则 | 来源（玩法） | 含义 |
|------|-------------|------|
| **地块优先** | "会频繁操作地块" | 地块是最高频交互对象，HUD 不能遮挡地块；地块选中/悬停反馈必须即时 |
| **指令模式** | "玩家所做的事是'发指令'" | UI 应提供清晰的指令入口（圈选、右键菜单、快捷键），而非让玩家逐帧微操 |
| **模态阻断** | "频繁开关仓库、商店等覆盖型UI界面（此时会阻止玩家操作地块和指挥单位）" | 仓库/商店/科技树等界面打开时必须**阻止底层交互**，关闭后恢复 |
| **快捷键驱动** | "会使用大量可配置的快捷键进行操作" | 所有常用操作必须支持快捷键，快捷键需可配置 |
| **种子选择前置** | "玩家在开局可以选择一个派系" | 游戏开始前有派系选择阶段，属于局外 UI |

## UI 分层架构

使用 Godot `CanvasLayer` 实现层级隔离，从上到下（渲染顺序 = 列表顺序）：

```
┌──────────────────────────────────────────────┐
│  Layer 5: Debug                              │
│  调试控制台（"/"键激活）、调试叠加层（F3开关）、│
│  Tick 计数标签、性能面板、开发者工具            │
│  → 永远在最上层，不受游戏状态影响              │
├──────────────────────────────────────────────┤
│  Layer 4: Popup                              │
│  悬浮提示框（Tooltip）、右键上下文菜单、        │
│  通知弹窗（敌人来袭警告等）、确认对话框         │
│  → 临时性，不阻止底层游戏逻辑，但可能阻止底层点击 │
├──────────────────────────────────────────────┤
│  Layer 3: Overlay（模态覆盖层）               │
│  仓库、商店、科技树、设置、结算界面             │
│  → 打开时阻止 Layer 1 的所有交互               │
│  → 同一时间只能打开一个 Overlay 界面            │
├──────────────────────────────────────────────┤
│  Layer 2: Selection & Command                │
│  框选矩形、指令预览（如开垦范围指示）、         │
│  单位移动目标指示器                            │
│  → 半透明标记层，随鼠标操作动态出现/消失        │
├──────────────────────────────────────────────┤
│  Layer 1: HUD（常驻）                         │
│  顶部资源栏、底部快捷栏、小地图、              │
│  选中单位/地块信息面板、游戏时间/速度、         │
│  事件通知条                                    │
│  → 始终可见，不阻止地块/单位交互               │
├──────────────────────────────────────────────┤
│  Layer 0: Game World                          │
│  地块、作物、单位、建筑等游戏实体               │
│  → 由 TerrainGenerator、UnitManager 等管理    │
└──────────────────────────────────────────────┘
```

**层级规则：**

- Layer 3（Overlay）同一时间只显示一个界面；新界面打开时关闭当前界面
- Layer 4（Popup）允许多个共存但需管理 z 序（最后打开的在最上方）
- 快捷键 `Esc` 按 Layer 4 → Layer 3 顺序逐层关闭，全部关闭后打开设置/暂停菜单
- Layer 2 的绘制通过 `_draw()` 或临时 Sprite 实现，非独立场景

## HUD 框架

HUD 是 Layer 1 常驻 UI，场景根节点为 `hud.tscn`，控制器脚本 `hud.gd`。

### 子组件

```
hud.tscn (CanvasLayer, layer = 1)
├── ResourceBar (HBoxContainer)           ← 顶部
│   ├── 金钱 (Label + Icon)
│   ├── 作物产量 (Label + Icon)
│   ├── 人口 (当前/上限) (Label + Icon)
│   └── (更多资源由 config 驱动)
│
├── ActionBar (HBoxContainer)             ← 底部居中
│   ├── 开垦 (Button, key: K)
│   ├── 种植 (Button, key: P)
│   ├── 建造 (Button, key: V)
│   ├── 收割 (Button, key: H)
│   ├── 仓库 (Button, key: I)
│   ├── 商店 (Button, key: B)
│   └── 科技树 (Button, key: T)
│
├── InfoPanel (PanelContainer)            ← 右侧或底部，动态显示/隐藏
│   ├── 地块信息（类型、湿度、硬度、是否可耕种）
│   ├── 单位信息（生命值、攻击力、状态）
│   └── 建筑信息（类型、生命值、生产进度）
│
├── Minimap (SubViewportContainer)        ← 右下角
│   └── 待实现：缩略地图渲染
│
├── NotificationBar (VBoxContainer)       ← 顶部居中，滚动显示
│   └── 事件通知项（收获完成、敌袭警告、科技完成等）
│
└── GameClock (Label)                     ← 右上角
    ├── 游戏时间显示
    └── 暂停/速度控制按钮
```

### HUD 信号（待 EventBus 注册）

| 信号 | 发出时机 | 监听者 |
|------|---------|--------|
| `resource_updated(resource_id, new_value)` | 任何资源数量变化 | ResourceBar |
| `tile_selected(tile_data)` | 点击地块 | InfoPanel（切换为地块模式） |
| `unit_selected(unit_data)` | 选中单位 | InfoPanel（切换为单位模式） |
| `building_selected(building_data)` | 选中建筑 | InfoPanel（切换为建筑模式） |
| `selection_cleared` | 点击空地 / Esc | InfoPanel（隐藏面板） |
| `notification_posted(text, level)` | 系统事件 | NotificationBar |
| `game_time_changed(tick_count)` | 每个 tick | GameClock |
| `overlay_opened(overlay_id)` | Overlay 打开 | HUD（隐藏 ActionBar 等） |
| `overlay_closed(overlay_id)` | Overlay 关闭 | HUD（恢复 ActionBar 等） |

## 覆盖型界面框架（Overlay）

所有 Overlay 界面共享以下契约：

### 通用契约

```gdscript
## Overlay 界面必须实现的接口契约（约定式，非继承强制）：
##
## 1. 打开：show_overlay() → 发出 overlay_opened 信号、阻止 Layer 1 交互
## 2. 关闭：hide_overlay() → 发出 overlay_closed 信号、恢复 Layer 1 交互
## 3. 数据绑定：bind_data(data: Dictionary) → 接收外部传入的数据
## 4. 快捷键：在 _input() 中处理，仅在 visible 时生效
```

## Popup 组件框架

### Tooltip（悬浮提示）

```
触发条件：鼠标悬停 > 0.5s
位置：跟随鼠标，偏移 (16, 16)
内容：由被悬浮对象提供（实现 get_tooltip_text() → String 或 get_tooltip_data() → Dictionary）
```

**Tooltip 类型：**

| 类型 | 触发对象 | 内容 |
|------|---------|------|
| 地块信息 | 鼠标悬停在地块上 | 类型、湿度、硬度、是否可耕种/可建造 |
| 物品信息 | 鼠标悬停在仓库/商店物品格上 | 名称、描述、属性、价格 |
| 单位信息 | 鼠标悬停在单位上 | 名称、生命值、攻击力、状态效果 |
| 科技信息 | 鼠标悬停在科技树节点上 | 名称、消耗、效果、前置条件 |
| 建筑信息 | 鼠标悬停在建筑上 | 名称、生命值、功能描述 |

### ContextMenu（右键菜单）

```
触发条件：右键点击游戏对象
位置：点击位置
结构：垂直按钮列表
行为：点击菜单项后执行操作 → 菜单关闭；点击菜单外任意位置 → 菜单关闭
```

| 右键目标 | 菜单项 |
|---------|--------|
| 空地 | 开垦、种植（如已开垦） |
| 地块(已种植) | 查看信息、收割、铲除 |
| 己方单位 | 移动指令、攻击指令、驻守、查看信息 |
| 敌方单位 | 攻击（选中己方后）、查看信息 |
| 建筑 | 查看信息、升级、拆除、设定集结点 |

### ConfirmDialog（确认框）

```
触发条件：执行不可逆操作（拆除建筑、丢弃物品、覆盖存档等）
结构：标题 + 描述 + [确认] [取消]
快捷键：Enter = 确认，Esc = 取消
```

### AlertPopup（警报弹窗）

```
触发条件：敌人来袭、资源告急、科技完成等
位置：屏幕中上方
行为：短暂显示后自动消失，或点击关闭
```

## 指令与选择系统

这是实现"玩家发指令"玩法的核心交互层（Layer 2）。

### 选择系统

```
选择模式      触发                    行为
─────────────────────────────────────────────────────
单选         左键单击 地块/单位/建筑   选中单个对象，InfoPanel 显示详情
框选         左键拖拽                  矩形选择框选中范围内多个己方单位
追加选择     Ctrl + 单击              在当前选中基础上添加
全选         Ctrl + A                 选中所有己方单位
取消选择     Esc / 点击空地              清空所有选中
```

### 指令系统

选中目标后，通过以下方式发出指令：

```
指令方式      触发                    行为
─────────────────────────────────────────────────────
右键点击空地  右键点击可通行地块      选中单位移动至目标点
右键点击敌人  右键点击敌方单位        选中单位攻击目标
右键点击作物  右键点击成熟作物        选中单位收割
拖拽开垦      K 键进入开垦模式        拖拽矩形 → 标记为开垦区域
拖拽种植      P 键进入种植模式        拖拽矩形 → 批量种植
放置建筑      V 键打开建造菜单        点击建造类型 → 放置模式
```

### 指令预览（Layer 2 视觉反馈）

| 操作 | 预览效果 |
|------|---------|
| 框选 | 半透明蓝色矩形（实时跟随鼠标） |
| 移动指令 | 虚线 + 箭头，从单位指向目标点 |
| 攻击指令 | 红色虚线，从单位指向目标敌人 |
| 开垦范围 | 绿色半透明矩形覆盖地块 |
| 建筑放置 | 建筑半透明预览 + 绿色(有效)/红色(无效)指示 |
| 建造进度 | 地块上的进度条叠加层 |

### 指令执行流程

```
玩家操作 → UI 发出指令事件 → EventBus 转发 → 对应系统执行
                                          → UI 显示反馈（成功/失败提示）
```

## UI ↔ 系统通信

### EventBus 信号扩展清单

以下信号需在 `event_bus.gd` 中注册，用于 UI 与游戏逻辑解耦：

```gdscript
## ========== 选择相关 ==========
## 选中地块。
signal tile_selected(tile_data: Resource)
## 选中单位。
signal unit_selected(unit_id: int)
## 选中建筑。
signal building_selected(building_id: int)
## 取消所有选中。
signal selection_cleared()

## ========== 指令相关 ==========
## 发布移动指令。
signal move_command(unit_ids: Array[int], target_position: Vector2)
## 发布攻击指令。
signal attack_command(unit_ids: Array[int], target_id: int)
## 发布开垦指令。
signal cultivate_command(area: Rect2i)
## 发布种植指令。
signal plant_command(area: Rect2i, crop_type: int)
## 发布收割指令。
signal harvest_command(area: Rect2i)

## ========== UI 状态相关 ==========
## Overlay 界面打开。
signal overlay_opened(overlay_id: StringName)
## Overlay 界面关闭。
signal overlay_closed(overlay_id: StringName)
## 放置模式激活（建造/种植等）。
signal placement_mode_entered(mode: StringName)
## 放置模式退出。
signal placement_mode_exited()

## ========== 通知相关 ==========
## 系统通知（显示在 NotificationBar）。
signal notification_posted(text: String, level: int)

## ========== 资源相关 ==========
## 资源数量变化。
signal resource_updated(resource_id: StringName, new_value: int, delta: int)
```

### 数据流示例

```
[玩家右键点击成熟作物]
     │
     ▼
[ContextMenu 发出] "收割"
     │
     ▼
[ContextMenu 调用] EventBus.harvest_command.emit(area)
     │
     ├──→ [CropManager 监听] 执行收割逻辑，产出资源
     │         │
     │         └──→ EventBus.resource_updated.emit("wheat", 150, +10)
     │                    │
     │                    └──→ [ResourceBar 监听] 更新显示
     │
     └──→ [NotificationBar 监听] 显示 "收获完成：小麦 +10"
```
