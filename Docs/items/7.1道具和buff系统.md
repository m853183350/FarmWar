# 道具和 Buff 系统

本章节记录道具系统的核心职责、架构设计、道具定义格式和扩展方向。Buff 系统为后续规划，当前暂不实现。

## 目标

- 为玩家提供**被动道具**收集机制（类似 roguelike 游戏中的道具/遗物）
- 道具通过**事件驱动**方式触发效果（监听 EventBus 信号）
- 采用**数据驱动**架构 — 道具定义存储在 JSON 配置文件中，无需为每个道具编写独立脚本
- 道具共性逻辑提取到 `PropManager` 和 `PropData` 中

## 范围

- **当前实现**：被动触发型道具（监听游戏事件 → 执行效果）
- **后续扩展**：消耗品、装备、Buff/Debuff 系统

## 核心概念

| 类/文件 | 类型 | 说明 |
|---------|------|------|
| `PropManager` | Node | 道具管理器，挂载在 Player 节点下，管理玩家持有的道具集合 |
| `EffectManager` | RefCounted | 效果管理器，管理效果注册表、条件评估和执行流程 |
| `PropData` | RefCounted | 道具定义数据类，从 JSON 配置文件解析，纯数据容器 |
| `PropEffectBase` | RefCounted | 效果基类，所有效果必须继承它 |
| `config/items/props/*.json` | JSON | 道具定义配置文件，每个道具一个文件 |

## 架构

```
Player (Node)
├── Storage (Storage)                # 仓库 — 物品存取
└── PropManager (PropManager)        # 道具管理器 — 道具持有与触发
    ├── props: Dictionary            # {prop_id: count}
    ├── prop_library: Dictionary     # {prop_id: PropData}
    ├── _signal_bindings: Dictionary # 信号→道具列表映射
    └── _effect_manager: EffectManager  # 效果管理器 — 效果注册与执行
        └── registry: Dictionary     # {effect_type: PropEffectBase}
```

## 道具属性（Roguelike 风格）

每个道具定义包含以下属性：

| 属性 | 类型 | 说明 |
|------|------|------|
| `prop_id` | String | 唯一标识符（snake_case） |
| `prop_name` | String | 显示名称（中文） |
| `description` | String | 风味描述文字 |
| `rarity` | String | 稀有度：COMMON / UNCOMMON / RARE / EPIC / LEGENDARY |
| `icon_path` | String | 图标纹理路径（暂可留空） |
| `max_stack` | int | 最大持有数量（0 = 无限制） |
| `trigger_signal` | String | 触发的 EventBus 信号名 |
| `trigger_condition` | Dictionary | 触发条件（预留：cooldown_ticks, probability 等） |
| `effect_type` | String | 效果类型标识 |
| `effect_params` | Dictionary | 效果参数 |
| `tags` | Array[String] | 分类标签（如 economy, crop, combat） |

## 触发-效果机制

### 触发信号（EventBus 信号 → 道具触发）

| 触发标识 | EventBus 信号 | 触发时机 | 信号参数 |
|----------|--------------|----------|---------|
| `crop_matured` | `crop_matured` | 作物进入成熟阶段 | `(crop_node, grid_pos, crop_id)` |
| `crop_harvested` | `crop_harvested` | 作物被收获 | `(yields, crop_id)` |
| `crop_stage_changed` | `crop_stage_changed` | 作物生长阶段变化 | `(crop_node, grid_pos, crop_id, old_stage, new_stage, is_mature)` |

### 效果类型

| 效果标识 | 类别 | 说明 | 参数 |
|----------|------|------|------|
| `add_storage_item` | INSTANT | 向 Storage 添加物品 | `item_id: String`, `amount: float` |

效果类别说明：[PropEffectBase.EffectCategory]
- **INSTANT** — 即时效果，触发时执行 count 次
- **MODIFIER** — 修饰效果，持有期间持续生效（预留）
- **DURATION** — 持续效果，限时 buff/debuff（预留）

后续可扩展：`multiply_harvest`（收获倍率）、`modify_growth`（生长加速）、`spawn_entity`（生成实体）等。

## 事件流（以 sunshine_coin 为例）

```
Crop._advance_stage()
  → EventBus.crop_matured.emit(crop_node, grid_pos, crop_id)
    → PropManager._on_crop_matured(crop_node, grid_pos, crop_id)
      → 构建 trigger_context {trigger_signal, crop_node, grid_pos, crop_id}
      → _process_trigger(&"crop_matured", trigger_context)
        → 查找所有绑定到 "crop_matured" 的道具
        → _effect_manager.execute(prop_data, count, trigger_context)
          → _build_context() 合并服务引用 {storage} + trigger_context
          → 查找 effect_type == "add_storage_item" 的效果实例
          → can_trigger(params, context) 条件评估
          → execute(params, context) × count
            → context["storage"].add_item("money", 1.0)
```

## 后续扩展

- 道具图标系统（`icon_path` 加载 Texture2D）
- 触发条件支持（冷却时间、触发概率）
- 更多效果类型（倍率、Buff 施加、实体生成）
- Buff/Debuff 系统（`BuffSystem`、`Buff`）
- 消耗品逻辑（`Consumable`）
- 道具获取途径（商店购买、掉落、奖励）
