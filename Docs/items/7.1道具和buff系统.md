# 道具和 Buff 系统

本章节记录道具和 Buff 系统的核心职责、道具类型、Buff 效果和持续时间管理。

## 目标

- 定义可获取、可使用、可消耗的"道具"实体
- 实现 Buff/Debuff 的施加、持续、叠加与移除
- 支持道具对单位、地块、作物的效果

## 范围

- 道具类型：消耗品（药水、肥料）、装备、特殊道具
- Buff 类型：属性增益（攻击+、速度+）、状态效果（中毒、灼烧、冰冻）
- Buff 管理：持续时间、叠加规则、驱散规则
- 效果目标：单位、地块、作物、建筑

## 核心概念

- `ItemBase` 所有道具的基类
- `BuffSystem` 管理所有活跃的 Buff 实例
- `Buff` 单个 Buff 的数据与逻辑（类型、数值、剩余时间、来源）
- `Consumable` 消耗品逻辑（使用即消失，施加效果）
