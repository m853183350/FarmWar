# 科技树系统

本章节记录科技树系统的核心职责、节点结构、研究机制和与其它系统的联动。

## 目标

- 定义科技树的节点结构与依赖关系
- 实现科技研究的消耗、时间与解锁逻辑
- 管理科技对其它系统的加成（作物产量、单位属性、建筑效果等）

## 范围

- 科技节点：每个节点有名称、前置依赖、研究消耗、解锁效果
- 科技分类：按"科"分类（禾本科科技、豆科科技等）以及通用科技
- 研究机制：消耗资源 → 等待时间 → 完成解锁
- 效果系统：科技解锁作物品种、强化单位、提升产量、解锁建筑等

## 核心概念

- `TechTree` 科技树的整体数据结构
- `TechNode` 单个科技节点的数据与逻辑
- `TechManager` 管理研究进度、解锁状态
