# 游戏流程控制

本章节记录游戏流程控制的核心职责、状态机和场景切换。

## 目标

- 管理游戏从启动到退出的完整生命周期
- 实现启动 → 主菜单 → 游戏中 → 结算 → 返回的流程
- 处理暂停、存档、读档、重新开始

## 范围

- 启动流程：Godot 启动 → 加载资源 → 初始化 Autoload → 进入主菜单
- 游戏流程：主菜单 → 新游戏/继续 → 加载世界 → 游戏循环 → 结算 → 返回主菜单
- 暂停：暂停游戏逻辑、打开暂停菜单
- 存档/读档：序列化游戏状态、恢复游戏状态

## 核心概念

- `GameFlow` 全局游戏状态机（Autoload）
- `Boot` 启动场景（资源预加载、初始化）
- `Lobby` 大厅/主菜单场景

## 状态机设计

```
Boot → MainMenu → (NewGame/LoadGame) → Playing → (Pause) → Playing
                                          Playing → GameOver → MainMenu
```
