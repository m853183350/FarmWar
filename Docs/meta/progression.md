# 局外成长系统

本章节记录局外成长系统的核心职责、升级路线和永久属性。

## 目标

- 定义玩家在单局之外的永久性成长
- 实现局外资源（经验/货币）积累与消耗
- 为重复游玩提供动力

## 范围

- 局外资源：通过完成对局获得（不论胜负）
- 永久升级：提升初始资源、解锁初始作物品种、基础属性加成
- 成长路线：多条升级路线供玩家选择

## 核心概念

- `Progression` 局外成长数据管理
- 升级节点：与科技树系统类似但跨局生效
- 局外经验/货币：独立于局内资源
