# 设置系统

本章节记录设置系统的核心职责、配置项和持久化方式。

## 目标

- 提供游戏内的可配置选项
- 管理配置的读取、修改、保存与重置

## 范围

- 音频设置：主音量、音乐音量、音效音量、静音
- 画面设置：分辨率、全屏/窗口、画质档位
- 游戏设置：语言、键位绑定、鼠标灵敏度
- 辅助功能：色盲模式、字幕等

## 核心概念

- `Settings` 设置数据管理（Autoload）
- 配置持久化：使用 Godot `ConfigFile` 读写 `user://settings.cfg`
- 配置变更信号：通知相关系统实时应用设置
