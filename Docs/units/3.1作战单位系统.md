# 作战单位系统

本章节记录作战单位系统的核心职责、概念、类型和战斗机制。

## 目标

- 定义可移动、可战斗的"作战单位"实体
- 规范单位属性（攻击力、防御力、生命值、移动速度等）
- 实现战斗计算、编队、寻路等功能

## 范围

- 单位类型：玩家单位、敌方单位、中立单位
- 单位属性：生命、攻击、防御、速度、射程等
- 战斗系统：伤害公式、护甲计算、暴击、元素克制
- 寻路系统：HPA\*（分层 A\*）网格寻路（8 方向斜向移动，JSON 配置移动成本，适合几百×几百大地图）
- 编队系统：多单位协同编队移动

## 核心概念

- `UnitBase` 是所有作战单位的基类
- `CombatStats` 封装单位的战斗属性
- `Formation` 管理编队中的单位位置与行为
- 单位与作物系统的关联：特定科作物解锁/强化对应兵种

## 寻路算法

可自主行动的单位的寻路算法都放在 `UnitBase` 基类中，根据需求调用。当前框架已预留寻路接口（`_move_path`、`_try_find_path()` 等），`pathfinding.gd`（独立寻路模块，`scripts/units/pathfinding.gd`）实现后接入。

详细设计见[Docs/units/3.1.1寻路算法.md](./3.1.1寻路算法.md)
