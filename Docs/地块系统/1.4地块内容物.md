# 地块内容物

本文档定义"地块内容物系统"——即附着在地块之上的所有对象，包括作物、建筑、道具、矿物等。内容物会改变地块的行为、属性和视觉效果。

---

## 核心概念

- **内容物（Content）** 是挂载在 `Tile` 节点上、影响地块状态的对象
- 每个地块可承载一个或多个内容物，取决于内容物类型和地块容量
- 内容物由其他系统（作物、建筑、道具等）创建和管理，地块系统负责容纳和查询

---

## 内容物分类

### 分类图

```
Content（内容物基类）
├── Crop         作物 / 植株
├── Building     建筑
├── ResourceNode 资源节点（矿物、宝藏）
├── Item         掉落物 / 放置物
├── Decoration   装饰物
├── Unit         临时占用（单位站位）
└── Effect       临时效果（预留）
```

---

## 一、作物 (Crop)

玩家种植的植物，占据地块直到被收获或枯萎。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `crop_id` | `StringName` | 作物品种 ID（如 `"wheat"`、`"rice"`） |
| `plant_family` | `StringName` | 所属"科"（如 `"poaceae"` = 禾本科） |
| `growth_stage` | `int` | 当前生长阶段 (0 = 刚种下) |
| `max_stage` | `int` | 最大生长阶段 |
| `health` | `float` | 当前生命值（病害/虫害会扣减） |
| `growth_progress` | `float` | 当前阶段内进度 (0.0 ~ 1.0) |
| `planted_tick` | `int` | 种植时的 tick 序号 |

### 地块限制

- 只能在 `FARMLAND` 地块上种植
- 每个地块最多种植 1 个作物（暂定，可扩展为多株）

### 对地块的影响

| 属性 | 影响 |
|------|------|
| `passable` | 视生长阶段：幼苗 `true`，成熟大型作物 `false` |
| `buildable` | `false`（有作物时不能盖建筑） |
| 视觉 | 替换或叠加作物精灵 |

### 扩展预留

- 多株种植（一个地块多棵）
- 攀爬作物（影响相邻地块）
- 水生作物（种于浅水）

---

## 二、建筑 (Building)

玩家或 AI 建造的结构物，提供防御、生产、存储等功能。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `building_id` | `StringName` | 建筑类型 ID |
| `size` | `Vector2i` | 占地面积（如 (2, 2) = 2×2 格） |
| `health` | `float` | 当前耐久 |
| `max_health` | `float` | 最大耐久 |
| `defense` | `int` | 防御值（减少敌方伤害） |
| `owner` | `int` | 所属方（0=玩家，1+=AI） |

### 地块限制

- 只能在 `buildable == true` 的地块上建造
- 可占据多个地块（大建筑），以建筑"锚点地块"为基准
- 占据地块的 `passable` 和 `buildable` 均变为 `false`

### 对地块的影响

| 属性 | 影响 |
|------|------|
| `passable` | `false` |
| `buildable` | `false` |
| `defense` | 叠加建筑的 defense 值 |

### 扩展预留

- 多格建筑 (multi-tile)
- 可通行建筑（门、桥）
- 地下建筑

---

## 三、资源节点 (ResourceNode)

天然附着于地块的资源，玩家可采集获取材料。由地形生成器在生成时分配。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `resource_type` | `StringName` | 资源类型（`"stone"`、`"iron"`、`"gold"`、`"wood"`） |
| `amount` | `int` | 剩余可采集量 |
| `max_amount` | `int` | 最大储量 |
| `harvest_hardness` | `int` | 采集难度（影响耗时） |
| `respawn` | `bool` | 采集完后是否可再生 |

### 地块限制

- 可附着于任何 `passable == true` 的地块（矿石在石质地面，木材在土质等）
- 采集完毕后变为普通地块（资源节点移除）

### 类型示例

| 资源 | 附着地 | 产出 | 采集后 |
|------|--------|------|--------|
| 石材矿脉 | STONE（坚硬石质） | 石材 × N | 变为 碎石地 |
| 铁矿 | STONE | 铁矿石 × N | 变为 碎石地 |
| 金矿 | STONE（稀有） | 金矿石 × N | 变为 卵石地 |
| 树木 | DIRT | 木材 × N | 变为 草地 |
| 鱼群 | OCEAN（浅水） | 鱼 × N | 鱼群消失（可重生） |

### 扩展预留

- 可再生资源（鱼群重生、树木再生）
- 宝藏（宝箱，一次性高价值）
- 水晶 / 符文（魔法系统预留）

---

## 四、掉落物 (Item)

从收获、击杀、拆除等行为产生的可拾取物品。临时存在于地块上。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `item_id` | `StringName` | 物品 ID |
| `stack_count` | `int` | 堆叠数量 |
| `expire_tick` | `int` | 消失 tick（超时自动清除） |
| `pickable` | `bool` | 是否可被拾取 |

### 地块限制

- 可堆积于任何 `passable == true` 的地块
- 同地块可堆多个掉落物堆

### 对地块的影响

- 不影响 `passable` / `buildable`
- 仅视觉添加小图标

---

## 五、装饰物 (Decoration)

纯粹的美术表现对象，不影响游戏逻辑（或影响极小）。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `decor_id` | `StringName` | 装饰物 ID |
| `offset` | `Vector2` | 在地块内的偏移 |

### 类型示例

- 草地上的花朵
- 水面的波纹
- 石质地面上的裂缝
- 农田边的稻草人（可能兼具功能）

---

## 六、临时单位 (Unit)

作战单位在地块上的临时占位。与"内容物"中的其他类型不同，单位是动态移动的。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `unit_ref` | `Node` | 单位节点引用 |
| `occupy_tick` | `int` | 开始占用的 tick |

### 地块限制

- 只能占据 `passable == true` 的地块
- 同一地块可容纳多个单位（受限于碰撞规则）

---

## 内容物数据结构

每个地块维护一个内容物列表，存储于 `TileInfo` 或地块节点 metadata 中：

```
tile.metadata:
  └── "contents": Array[ContentData]

ContentData:
  ├── type: ContentType (枚举)
  ├── id: StringName
  ├── data: Dictionary  (各类型的自定义数据)
  └── instance: NodePath (场景实例引用，可选)
```

### ContentType 枚举

```gdscript
enum ContentType {
    CROP,
    BUILDING,
    RESOURCE_NODE,
    ITEM,
    DECORATION,
    UNIT,
    EFFECT,
}
```

## 内容物优先级与冲突

同一地块上不同内容物类型的共存规则：

| | Crop | Building | ResourceNode | Item | Decoration | Unit |
|--|------|----------|-------------|------|------------|------|
| **Crop** | ✗ 唯一 | ✗ | ✗ | ✓ | ✓ | ✓ |
| **Building** | ✗ | ✗ 或叠（大建筑） | ✗ | ✗ | ✓ | ✗ |
| **ResourceNode** | ✗ | ✗ | ✓ 可叠 | ✓ | ✓ | ✓ |
| **Item** | ✓ | ✗ | ✓ | ✓ 同地块多堆 | ✓ | ✓ |
| **Decoration** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **Unit** | ✓ | ✗ | ✓ | ✓ | ✓ | ✓ 多单位 |

> ✓ = 可共存，✗ = 不可共存

## 查询与操作接口（规划）

地块系统应提供以下内容物操作：

```gdscript
# 添加内容物
tile.add_content(type: ContentType, data: Dictionary) -> bool

# 移除内容物
tile.remove_content(type: ContentType, id: StringName) -> bool

# 查询
tile.has_content_of_type(type: ContentType) -> bool
tile.get_contents_of_type(type: ContentType) -> Array
tile.get_all_contents() -> Array

# 检查是否可放置
tile.can_place_content(type: ContentType) -> bool
```
