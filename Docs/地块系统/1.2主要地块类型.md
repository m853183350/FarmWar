# 主要地块类型

本文档详细定义 FarmWar 中所有地块大类、变种、属性值以及类型转换规则。是地块系统最核心的参考文档。

> 本文与 `1.1地块系统.md` 配合使用：1.1 描述架构和数据流，本文档描述具体数据。

---

## 地块分类体系

### 分类层级

```
TileType（大类）
├── DIRT      土质地面
│   ├── 草地     (grassland)
│   ├── 普通土壤 (soil)
│   ├── 沙地     (sand)
│   └── 湿地     (wetland)
├── STONE     石质地面
│   ├── 碎石地   (gravel)
│   ├── 卵石地   (pebble)
│   └── 坚硬石质 (hard_stone)
├── FARMLAND  农田 *
│   └── （无变种，通过耕作行为由 DIRT 转化）
├── OCEAN     水域
│   ├── 浅水     (shallow)
│   ├── 深水     (deep)
│   └── 河流     (river)
├── SLOPE     斜坡（预留）
├── ROUGH     崎岖地块（预留）
└── SPECIAL   特殊地块（预留）
```

> \* FARMLAND 不是自然生成的地块，而是通过玩家行为（耕作）由 DIRT 转化而来。

---

## 一、土质地面 (DIRT)

最常见的地块类型，是玩家耕作、建造的基础。默认可通行、可建造、可转化为农田。

### 通用属性

| 属性 | 值 |  描述 |
|------|-----|--|
| `passable` | `true` | 地面单位是否可通行 |
| `buildable` | `true` | 是否可建造建筑物 |
| `can_be_farmed` | `true`|（可被转化为 FARMLAND） |
| `moisture` | 1 | 湿度，该属性会受到修正倍率、气候、水源距离、浇水等动作的影响 |
| `fertility` | 1 | 肥力，该属性会受到修正倍率、施肥等动作影响 |
| `temperature` | 25 | 温度，由地形和天气直接决定 |
| `description` | "" | 描述，这个属性后面不在表里，单独写 |

### 变种详情

#### 草地 (grassland)

| 属性 | 值 | 说明 |
|------|-----|------|
| `hardness` | 1 | 默认硬度 |
| `grass_rate` | 0.2 | 杂草概率 |
| `moisture_fix` | 0.8 | 普通保湿 |
| `fertility_fix` | 0.8 | 普通肥力 |

description：默认泥土类型。青草覆盖的平地，没什么特别的，绿色的，比裸露的泥土好看一些。上面可能会有杂草，耕作可能获得种子。

#### 普通土壤 (soil)

| 属性 | 值 | 说明 |
|------|-----|------|
| `hardness` | 1 | 默认硬度 |
| `moisture_fix` | 0.8 | 普通保湿 |
| `fertility_fix` | 0.8 | 普通肥力 |

description：深棕色裸土，无植被。最"标准"的耕地原料，各项属性均衡。

#### 沙地 (sand)

| 属性 | 值 | 说明 |
|------|-----|------|
| `hardness` | 1 | 默认硬度 |
| `moisture` | 0.1 | 极低保湿性 |
| `fertility` | 0.2 | 贫瘠 |
| `is_farmland` | `true` | 已是农田，可直接种植 |

description：浅黄色的沙质地面。肥力与保湿性都很差，但可后期通过灌溉和施肥改良。适合特定作物（如仙人掌类，预留）。

#### 湿地 (wetland)

| 属性 | 值 | 说明 |
|------|-----|------|
| `hardness` | 1 | 默认硬度 |
| `moisture` | 1.8 | 高湿度 |
| `fertility` | 1.0 | 较高肥力 |

description：沼泽地。湿度极高，适合水稻等喜水作物（预留"科"系统）。但过高的湿度导致前期难以利用。

### 扩展预留

| 变种 | 方向 |
|------|------|
| 冻土 (frozen_soil) | 寒冷地区，需解冻才可耕作 |
| 火山灰土 (volcanic) | 极高肥力但稀有 |
| 腐殖土 (humus) | 森林地带，肥力最高 |

## 二、石质地面 (STONE)

石块覆盖的平地，可通行但不可耕种。可被清理/挖掘转化为土质地面。

### 通用属性

| 属性 | 值 |
|------|-----|
| `passable` | `true` |
| `buildable` | `true`（部分需先清理） |
| `can_be_farmed` | `false` |
| `farmland` | `false` |
| `description` | "" | 描述，这个属性后面不在表里，单独写 |

### 变种详情

#### 碎石地 (gravel)

| 属性 | 值 | 说明 |
|------|-----|------|
| `hardness` | 2 | 较易清理 |
| `can_produce` | 石材 × 2~4 | 清理后可获得石材资源 |

description：小碎石与砂砾混合的地面。硬度较低，用基础工具即可清理。清理后地块变为"普通土壤"。

#### 卵石地 (pebble)

| 属性 | 值 | 说明 |
|------|-----|------|
| `hardness` | 3 | 中等硬度 |
| `can_produce` | 石材 × 3~6 | 中等石材产出 |

description：较大的鹅卵石地面。需要更好工具清理，但产出更高。

#### 坚硬石质 (hard_stone)

| 属性 | 值 | 说明 |
|------|-----|------|
| `hardness` | 5 | 需要高级工具 |
| `can_produce` | 石材 × 5~10，矿物可能 | 高产出，有概率出稀有矿物 |

description：坚硬的岩石地表。需要高级工具或炸药清理。高投入高回报，可能伴随矿物。

### 清理流程

```
STONE（任意变种）──→ 玩家"挖掘"动作 ──→ 检查工具等级 ──→ 成功
                                                      │
                                    原石质地块 ──→ 替换为 DIRT（普通土壤）
                                    产出：石材 + 可能矿物
```

### 扩展预留

| 变种 | 方向 |
|------|------|
| 矿脉 (ore_vein) | 含金属矿，可建造采矿建筑 |
| 宝石矿 (gem_deposit) | 稀有宝石产出 |
| 废墟石 (ruins) | 含古代遗物 |

## 三、农田 (FARMLAND)

玩家通过"耕作"动作将 DIRT 地块转化而来。

### 通用属性

| 属性 | 值 |
|------|-----|
| `passable` | `true` |
| `buildable` | `false`（农田上不可直接盖建筑，需先"退耕"） |
| `can_be_farmed` | `true`（已是农田） |
| `is_farmland` | `true` |

### 耕作属性（农田专属）

农田在基础地块属性外，额外拥有以下农业属性：

| 属性 | 类型 | 范围 | 说明 |
|------|------|------|------|
| `fertility` | `float` | 0.0 ~ 5.0 | 土壤肥力。继承自源 DIRT 变种，随种植消耗，可通过施肥补充 |
| `moisture` | `float` | 0.0 ~ 5.0 | 当前湿度。受天气、灌溉、蒸发影响 |
| `fallow_turns` | `int` | 0 ~ N | 连续种植回合数。目前仅作为计数器使用 |

#### 土质农田

description：由草地和普通土壤变化而来

#### 淤泥农田

description：由湿地变化而来

#### 沙地 (sand)

**注意** 该地块和前面的沙地是完全相同的东西，不要重复实现。沙地无需耕作即可种植作物

| 属性 | 值 | 说明 |
|------|-----|------|
| `hardness` | 1 | 默认硬度 |
| `moisture_fix` | 0.1 | 极低保湿性 |
| `fertility_fix` | 0.2 | 贫瘠 |
| `is_farmland` | `true` | 已是农田，可直接种植 |

description：浅黄色的沙质地面。肥力与保湿性都很差，但可后期通过灌溉和施肥改良。适合特定作物（如仙人掌类，预留）。

### 肥力公式（草案）
×
```
计算公式：(基础值 + 肥料修正值1) × 地块属性修正倍率 + 肥料修正值2
```

### 湿度公式（草案）

```
计算公式：(基础值 + 水修正值1) × 地块属性修正倍率 + 水修正值2
```

### 农田状态转换

```
DIRT ──→ [耕作] ──→ FARMLAND (till_quality 由工具和技能决定)
FARMLAND ──→ [退耕] ──→ DIRT (原变种，肥力重置为默认)
FARMLAND ──→ [荒芜] ──→ DIRT (长期未管理，肥力降低)
```

### 扩展预留

| 概念 | 方向 |
|------|------|
| 梯田 (terraced) | 斜坡变种，需额外工程 |
| 水田 (paddy) | 特殊灌溉农田（水稻等） |
| 温室 (greenhouse) | 建筑覆盖的农田，不受天气影响 |

## 四、水域 (OCEAN)

水面覆盖的地块。不可通行、不可建造、不可耕种。是地图的天然边界和障碍物。

### 通用属性

| 属性 | 值 |
|------|-----|
| `passable` | `false` |
| `buildable` | `false` |
| `can_be_farmed` | `false` |
| `moisture` | `10.0` |

### 变种详情

#### 浅水 (shallow)

| 属性 | 值 | 说明 |
|------|-----|------|
| `depth` | 0.3 | 较浅，视觉效果透明 |
| `fishable` | `true` | 可钓鱼 |

近岸浅水区域。未来可通过"填平"转化为土质地面，也可用于捕鱼。

#### 深水 (deep)

| 属性 | 值 | 说明 |
|------|-----|------|
| `depth` | 1.0 | 深海，完全不可操作 |
| `fishable` | `true` | 可钓鱼，产出优于浅水 |

远离海岸的深水区。不可填平，作为地图天然边界。可能产特殊鱼种。

### 水域专属属性

| 属性 | 类型 | 范围 | 说明 |
|------|------|------|------|
| `depth` | `float` | 0.0 ~ 1.0 | 水深，影响填平成本和视觉效果 |
| `flow_direction` | `Vector2i` | — | 水流方向（河流专属，预留） |
| `fishable` | `bool` | — | 是否可钓鱼 |

### 扩展预留

| 变种 | 方向 |
|------|------|
| 河流 (river) | 有流向的线性水域，可灌溉沿岸 |
| 沼泽 (swamp) | 浅水+泥地混合，可排水转化 |
| 岩浆 (lava) | 特殊地图主题，不可接近 |

## 属性继承规则

当一种地块转化为另一种时，部分属性需要继承或重置：

| 转化 | 继承 | 重置 |
|------|------|------|
| DIRT → FARMLAND | 坐标、fertility、moisture（继承源值） | — |
| FARMLAND → DIRT | 坐标 | fertility 回默认、till_quality 清除 |
| STONE → DIRT | 坐标 | 全部重置为"普通土壤"默认值 |
| SHALLOW → DIRT | 坐标 | 全部重置（填平后为湿地或普通土壤） |
