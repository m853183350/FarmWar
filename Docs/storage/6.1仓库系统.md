# 仓库系统

本章节记录仓库系统的核心职责、数据结构、存取操作和容量管理。

## 目标

- 管理玩家拥有的所有物品及其数量
- 提供增删查改接口供其他系统调用
- 限制容量，创造资源管理策略空间

## 范围

- 物品存储：作物收获物、道具、装备、材料等
- 容量管理：基础容量、可扩展容量
- 存取操作：入仓（收获）、出仓（使用/出售/消耗）
- 与 UI 的桥接：数据模型与界面显示的同步

## 核心概念

- `Inventory` 管理物品列表与数量
- `ItemData` 物品数据结构（ID、名称、类型、数量、属性）
- `StorageUIBridge` 仓库数据与 UI 的信号桥接
