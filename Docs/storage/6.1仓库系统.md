# 仓库系统

本章节记录仓库系统的核心职责、数据结构、存取操作和容量管理。

## 目标

- 管理玩家拥有的所有物品及其数量
- 提供增删查改接口供其他系统调用
- 限制容量，创造资源管理策略空间

## 范围

- 物品存储：作物收获物、道具、装备、材料等
- 容量管理：基础容量、可扩展容量
- 存取操作：入仓（收获）、出仓（使用/出售/消耗）
- 与 UI 的桥接：数据模型与界面显示的同步

## 核心概念

- `Inventory` 管理物品列表与数量
- `ItemData` 物品数据结构（ID、名称、类型、数量、属性）
- `StorageUIBridge` 仓库数据与 UI 的信号桥接

## 当前状态

✅ 已实现基础仓库系统（2026-06-06）

- [Storage](storage.md) 类：分区式物品存储，4 个分区（farm_products / items / pending_1 / pending_2）
- 通过 `EventBus.crop_harvested` 事件自动收集作物收获产物
- 控制台 `print_contents()` 展示仓库内容
- JSON 物品目录（[item_catalog.md](item_catalog.md)）
- Player 节点承载 Storage 子节点

待实现：
- 容量上限与扩展方式
- 物品堆叠规则
- 快捷栏/常用物品机制
- UI 界面
